# Legowelt's Juno 106 samples packaged for strudel

I couldn't find a repo that had any of Legowelt's synth sample packs packaged for use with strudel, so I decided to make one on my own!
This contains all of the samples from the Roland Juno 106 synthesizer sample pack on legowelt.org/samples
All credit goes to Legowelt at legowelt.org
If you like these samples, please consider donating to their paypal.
